# 何田田的旅行攻略 · 使用说明

把路上的细节，留成可复用的路书。

这是一个**可以离线打开的旅行攻略网站**。首页是攻略卡片墙，点进去是完整的逐日行程，包含交通、每天几点去哪、吃什么、花多少钱、要注意什么。

**在线访问：https://creamshi0208.github.io/TianTravel/**

---

## 一、怎么打开

| 方式 | 做法 | 适合 |
|---|---|---|
| **在线** | 浏览器打开 https://creamshi0208.github.io/TianTravel/ | 分享给别人、手机上看 |
| **本地** | 双击 `index.html` | 没网也能看，比如路上、山里、高铁上 |
| **手机** | 浏览器打开后「添加到主屏幕」，会像 App 一样有图标 | 出行途中随时查 |

整个网站只有 `index.html` 一个文件，**不联网也能完整浏览**（文字、表格、实拍图全都在文件里）。

## 二、首页怎么用

首页分三部分：**标题区 → 筛选区 → 攻略卡片**。

### 1. 标题区

显示一行统计：共几篇攻略、覆盖几个目的地、收录多少张实拍图。数字会随收录的攻略自动变化。

### 2. 筛选区（两级分类）

筛选区有两行，**先选省份、再选地级市**：

```
省份    [全部]  [江西]
地级市  [全部]  [南昌]
```

| 操作 | 会发生什么 |
|---|---|
| 点某个**省份** | 卡片只显示该省；下面「地级市」一行**自动变成该省下辖的市**，只列有的城市 |
| 点某个**地级市** | 在当前省份范围内进一步筛到具体城市 |
| 直接点**地级市**（不选省份） | 也可以，会跨省筛出所有该城市的攻略 |
| 点**全部** | 清空该层级条件；点省份的「全部」时，城市会自动重置为「全部」 |
| 每个选项后的**小数字** | 该分类下有几篇攻略，0 篇的不会列出来 |

筛不出结果时会显示「该分类下暂无攻略」，不会出现空白页。

### 3. 攻略卡片

每张卡片从上到下是：**封面图 + 分类角标**（左上角）→ **标题** → **一行小字**（这趟行程大致包含哪些景点）→ **一句话简介** → **标签** → **关键信息**（行程天数、预算、所在省份）。

- **单击卡片** → 进入该篇攻略详情
- 标题下的那行小字**固定只占一行**，太长会自动省略；鼠标悬停可以看到完整内容
- 卡片区末尾的 `＋ 更多攻略陆续加入` 是占位卡，不是链接，点不开

## 三、攻略详情页怎么用

### 顶部常驻的返回按钮

进入任意一篇攻略后，**页面最顶上那条白栏会变成 `← 返回全部攻略` 按钮**。它**固定在窗口顶部**，不管往下滑多远都一直停在最上方，随时点一下就能回到首页列表。

回到首页之后，**再按浏览器的后退键不会退进刚才那篇攻略**（不会出现「明明点了返回、还能一路退回去」的情况），再按就退出站点了。

手机上旁边还有一个**「分享」按钮**，点了会直接调出系统的分享面板（微信、QQ 等），把这篇攻略的链接发出去；电脑浏览器没有这个面板，按钮会自动隐藏。

### 顶部红色区域

- 标题、**一行小字**（行程主要景点概述）、一行**副标题**（时间 / 人群 / 出发地），以及若干**标签胶囊**（如「高铁往返」「3天2晚」）

> 攻略详情**只在你点进去之后才出现**。停留在首页时，页面里不会有任何详情内容；每次点开一篇攻略，页面都从这篇的**最开头**（红色标题区）直接开始，**没有滚动过渡动画** —— 哪怕你是在首页滑到最底部才点的卡片。刷新页面同样从头开始，不会停在上次滑到的位置。

### 本页目录

正文开头有一个白底盒子「**本页目录**」，列出这篇攻略的所有章节，比如：

```
一、交通          五、重要提示
二、行程概览      六、行程距离表
三、每日详细行程   七、餐饮推荐
四、预算          八、景点实拍图
```

**点任意一项会平滑滚动到对应章节**，不用自己往下翻。想回顶部时，先把页面往下滑一段，**右下角会浮出一个圆形按钮**，点它平滑回到页首。

页面最顶端还有一条**细细的红色进度条**，随你往下翻页变长，一眼能看出这篇攻略读到哪里了。

### 正文能看到什么

正文按章节组织，每章一个白底卡片。内容形式有这几种：

| 形式 | 长什么样 | 用来看什么 |
|---|---|---|
| **正文段落** | 普通文字 | 背景说明、注意事项 |
| **提示条** | 带色块的独立小卡 | ⚠️ 重点提醒，比如抢票、预约、避坑 |
| **清单** | 带项目符号的列表 | 要带的东西、逐条要点 |
| **表格** | 规整的表 | 比价、票价、车次对比 |
| **时间轴** | 按时间排列的条目 | 每天几点做什么，一条一条排下来 |
| **路线卡** | 带编号的地点卡 | 一天里按顺序要去的几个点 |
| **餐饮卡** | 带店名的卡片 | 推荐吃什么、在哪吃、人均多少 |
| **图集** | 多张实拍图 | 景点、菜品实拍，看下长什么样 |

**图集里的图片可以点开放大**：点任意一张图会全屏显示大图（图上角标有「点击放大」字样），看细节更清楚；点屏幕任意位置或右上角 × 即可关闭。

### 每天的行程怎么看

在「每日详细行程」章节里，**每一天是一个独立区块**，开头标注日期和星期，然后依次是当天的路线、时间轴、餐饮安排。预算在对应章节里用表格摊开（交通多少、住多少、吃多少、门票多少），并给出合计和建议备用金额。

## 四、手机上怎么用

页面是响应式的，手机竖屏会自动变成单列，文字和图片适应屏幕宽度，表格可以左右滑动查看完整内容。

**建议添加到主屏幕**：手机浏览器打开站点 → 菜单里选「添加到主屏幕」→ 桌面会出现「何田田的旅行攻略」图标，之后一点就开，不用再输网址。

## 五、分享给别人

- **发链接**：直接发 https://creamshi0208.github.io/TianTravel/ 即可，对方不用装任何东西
- **发某一篇**：进入那篇攻略后复制地址栏链接（形如 `.../TianTravel/#/nanchang-3d`），对方打开就直达该篇。分享出去的**标题和简介会自动变成这篇的名字**，不会三篇都显示成同一个首页标题
- **发文件**：把 `index.html` 单独发微信 / 邮件 / 网盘也行，对方下载后双击就能看，**里面已经包含了所有图片**
- **拷进 U 盘 / 存本地**：单文件，不依赖任何文件夹和网络

## 六、常见问题

**打开是一片空白？**
多为浏览器缓存导致。按 `Ctrl + F5` 强制刷新一次。

**筛选点了没反应？**
筛选和页面切换都需要浏览器启用 JavaScript（默认都是开着的）。万一被禁用了，页面会只显示首页的攻略卡片墙，点不进详情 —— 在浏览器设置里把 JavaScript 打开即可。

**图片显示不出来？**
图片是内嵌在文件里的，正常不会失败。若出现，先刷新页面。

**手机上表格看不全？**
宽表格支持左右滑动，用手指横向拖动即可。表格右侧会出现一条淡淡的阴影，提示「右边还有内容」；滑到底阴影会自动消失。

**链接发给别人打不开？**
确认发的是完整链接（含末尾的 `/`），并且对方网络能访问 github.io。

**想打印出来随身带？**
浏览器里 `Ctrl + P`（手机用系统分享菜单里的「打印」）即可，也可以直接「另存为 PDF」。打印时会自动去掉顶栏、返回/分享按钮、悬浮按钮和图片上的「点击放大」角标，卡片和表格也不会从中间被拆到两页。

**分享到微信/微博没有封面图？**
图片全部内嵌在单文件里，社交平台的抓取器读不到，所以卡片不带图。需要带图的话得把封面单独上传到仓库，给它一个 http 地址再引用。
